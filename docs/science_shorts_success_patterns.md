# Science Shorts success-pattern experiment

This branch deliberately tests a different production strategy from the
diagram-heavy Mpemba short.

Observed public patterns used:
1. Result/event first, not topic introduction.
2. A familiar object doing one visibly strange thing.
3. Real motion in the opening when the phenomenon is intrinsically visual.
4. One mechanism per short instead of stacking several plausible causes.
5. Progressive disclosure: result -> expectation -> clue -> mechanism -> reversal -> payoff.
6. Every visual state must add information; crop/zoom of the same still is not cadence.
7. Keep scientific uncertainty where it exists, but do not bury a simple well-supported mechanism under caveats.

Experiment topic: Leidenfrost effect.
Opening evidence: real open-access 300 C Leidenfrost experiment (CC BY 4.0).
All explanation diagrams: generated locally by scripts/build_leidenfrost_states.py.
