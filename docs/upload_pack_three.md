# Upload Pack Three — production rationale

Three upload candidates built from the success-pattern work on PR #34.

## Shared structure
- familiar object + visible contradiction in the first seconds;
- HOOK -> CRISIS -> REVEAL inside the first 10 seconds;
- one causal spine per Short;
- motion represents the phenomenon itself, never camera crop/zoom churn;
- top title is opening-only;
- large visual primitives, no small explanatory paragraph text;
- payoff ends the video; no generic CTA or duration padding.

## Topics
1. Golf-ball dimples — counterintuitive aerodynamics.
2. Head restraint — hidden safety function in an everyday car component.
3. Elevator counterweight — hidden infrastructure and energy balance.

All visual assets are generated locally by the production script. External
sources are factual references only, so the final MP4s carry no third-party
media-license dependency.

No YouTube upload is part of this workflow.
