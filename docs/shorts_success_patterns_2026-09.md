# Short-form science reference patterns — 2026-09

This experiment starts from reference analysis rather than another post-hoc
detector.

## Reference set

- Zack D. Films recent science/safety Shorts: familiar noun + visible abnormal
  action/consequence.
- The Rest Is Science Shorts: compact propositions/questions that can be
  pictured immediately.
- YouTube Shorts guidance: the first instant should cash the title's promise;
  ranking observes chose-to-view, average view duration, average percentage
  viewed, and satisfaction.

## Cross-video patterns to test

1. Result/action first; name the phenomenon later.
2. One familiar subject + one contradiction.
3. Visual proof before explanation.
4. One causal spine instead of a list of adjacent facts.
5. Progressive disclosure: expectation -> observation -> mechanism -> payoff.
6. No persistent slide chrome.
7. Motion is evidence; repeated crop/zoom is not.
8. Specific payoff or topic-specific invitation, never generic CTA.
9. No fixed runtime quota; stop when the gap is closed.

## New production

Topic: Leidenfrost effect.

Hook hypothesis: **팬이 더 뜨거워질수록 물방울이 오히려 더 오래 남을 수
있습니다.**

This topic gives the experiment an everyday object, an immediate visible
contradiction, real motion, and one clean mechanism: a vapor cushion reduces
direct contact and heat transfer.
